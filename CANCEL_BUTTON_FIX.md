# Добавление кнопки "Отмена" в диалог сохранения версий

## Проблема

В диалоге сохранения версий перед удалением файла были только кнопки "Да" и "Нет". При нажатии крестика окна операция удаления продолжалась, что приводило к потере данных.

## Решение

Добавлена кнопка "Отмена" в диалог сохранения версий, которая полностью прерывает операцию удаления.

### Изменения в `FileEditDialog.py`

**Было:**
```python
restore = QMessageBox.question(
    self,
    "Сохранение версий перед удалением",
    f"В контейнере есть {len(versions_data)} версий.\n"
    "Сохранить их на диск перед удалением из контейнера?\n"
    "(в том виде, в каком они хранятся — зашифрованные или открытые)",
    QMessageBox.Yes | QMessageBox.No
)
```

**Стало:**
```python
restore = QMessageBox.question(
    self,
    "Сохранение версий перед удалением",
    f"В контейнере есть {len(versions_data)} версий.\n"
    "Сохранить их на диск перед удалением из контейнера?\n"
    "(в том виде, в каком они хранятся — зашифрованные или открытые)",
    QMessageBox.Yes | QMessageBox.No | QMessageBox.Cancel
)

if restore == QMessageBox.Cancel:
    # Пользователь нажал "Отмена" - полностью отменяем операцию удаления
    QMessageBox.information(self, "Отмена", "Операция удаления отменена")
    return  # Полная отмена операции удаления
```

## Поток выполнения операций удаления

### Полная схема отмен:

1. **Основной диалог удаления файла:**
   - "Да" - удалить всё
   - "Нет" - оставить оригинал, удалить из БД/контейнера  
   - "Отмена" - полная отмена операции ✅

2. **Диалог сохранения версий (если есть версии и выбрано "Нет"):**
   - "Да" - сохранить версии перед удалением
   - "Нет" - удалить без сохранения
   - **"Отмена" - полная отмена операции удаления** ✅

3. **Диалог выбора папки (если выбрано сохранение):**
   - Выбор папки → продолжение
   - **"Отмена" → showMessage("Операция удаления отменена") → полная отмена** ✅

4. **Диалог ввода пароля (если файл зашифрован):**
   - Ввод пароля → продолжение
   - **"Отмена" → showMessage("Операция удаления отменена") → полная отмена** ✅

5. **Прогресс-бар удаления:**
   - Выполнение удаления
   - **Кнопка "Отмена" / крестик → отмена потока → полная отмена** ✅

## Поведение для пользователя

Теперь при удалении файла с версиями пользователь имеет **полный контроль** над операцией:

1. **Диалог сохранения версий** показывает 3 кнопки:
   - **Да** - сохранить версии и удалить файл
   - **Нет** - удалить без сохранения версий
   - **Отмена** - полностью отменить удаление

2. **При нажатии "Отмена"** на любом этапе:
   - Показывается сообщение: "Операция удаления отменена"
   - Операция немедленно прерывается
   - Файл и все версии остаются нетронутыми
   - Диалог закрывается

3. **Консистентное поведение**:
   - Все диалоги имеют кнопку "Отмена"
   - Все отмены работают одинаково
   - Нет случайных потерь данных
