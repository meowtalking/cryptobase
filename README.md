# CryptoBase

**CryptoBase** - безопасное хранилище файлов с версионностью и шифрованием.

## 🚀 Быстрый старт

### Установка
```bash
# Клонируйте репозиторий
git clone <repository-url>
cd cryptobase

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python app/main.py
```

### Первый запуск
1. Приложение создаст защищенную директорию `~/.cryptobase/`
2. Установит права доступа 700/600
3. Сгенерирует соль для мастер-ключа
4. Запросит мастер-пароль для защиты данных

## ✨ Основные возможности

- 🔐 **Шифрование файлов** - AES-256-GCM защита данных
- 📚 **Версионность** - автоматическое сохранение всех изменений
- 👁️ **Мониторинг** - отслеживание изменений в реальном времени
- 🔄 **Восстановление** - восстановление любой версии файла
- ❌ **Безопасное удаление** - с возможностью отмены
- 🛡️ **Защита паролей** - bcrypt + Argon2

## 🎯 Как это работает

### Добавление файлов
1. Нажмите "Добавить файл" в главном окне
2. Выберите файл на диске
3. Укажите пароль для шифрования (опционально)
4. Файл добавляется в систему с созданием первой версии

### Управление версиями
- **Автоматически**: FileWatcher отслеживает изменения
- **Вручную**: Через контекстное меню файла
- **Ограничение**: Настраивается в настройках (по умолчанию 5 версий)

### Восстановление
1. Выберите файл в таблице
2. Нажмите "Восстановить версию"
3. Выберите нужную версию из списка
4. Укажите место сохранения

### Удаление файлов
1. Выберите файл для удаления
2. Выберите стратегию:
   - **Да** - удалить всё (файл + версии + запись)
   - **Нет** - оставить оригинал, удалить из системы
   - **Отмена** - прервать операцию
3. При необходимости сохраните версии перед удалением

## 🔐 Безопасность

- **Мастер-пароль**: Argon2 с солью для защиты приложения
- **Пароли файлов**: bcrypt хэши в базе данных
- **Шифрование**: AES-256-GCM для контейнера версий
- **Права доступа**: 700 на директорию, 600 на файлы
- **Автоблокировка**: Настраиваемая (по умолчанию 30 минут)

## 📁 Хранилище

```
~/.cryptobase/
├── backups.enc          # Зашифрованные версии файлов
├── master_hash.bin      # Хэш мастер-пароля
├── master_salt.bin      # Соль для мастер-ключа
└── cryptobase.db        # База данных SQLite
```

## ⚙️ Настройки

Настройки хранятся в `app/ui/settings.json`:

```json
{
    "auto_lock_minutes": 30,  # Автоблокировка (минуты)
    "max_versions": 5         # Макс. версий на файл
}
```

## 🐛 Troubleshooting

### Проблема: "Неверный ключ или повреждён контейнер"
**Решение**: Проверьте мастер-пароль. Контейнер шифруется мастер-ключом.

### Проблема: Файлы не отслеживаются
**Решение**: Проверьте, что FileWatcher запущен. Перезапустите приложение.

### Проблема: Нет доступа к ~/.cryptobase
**Решение**: 
```bash
chmod 700 ~/.cryptobase
chmod 600 ~/.cryptobase/*
```
