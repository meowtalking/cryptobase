## Поток выполнения операций

### Удаление версии:
1. Пользователь выбирает версию → подтверждение пароля → подтверждение удаления
2. Запускается `_start_version_deleting_process()` с прогресс-баром
3. Создается `VersionDeleteWorker` (QThread)
4. Пользователь может отменить в любой момент (крестик/кнопка "Отмена")
5. Результат обрабатывается в `_on_version_deleted()`

### Удаление файла:
1. Пользователь выбирает стратегию удаления → подтверждение пароля
2. Запускается `_start_file_deleting_process()` с прогресс-баром
3. Создается `FileDeleteWorker` → `DeleteFileThread`
4. Пользователь может отменить в любой момент
5. Результат обрабатывается в `_on_delete_finished()`

## Использование

Теперь при удалении файлов или версий:

1. **Появляется прогресс-бар** с текущей операцией
2. **Можно отменить** в любой момент:
   - Нажать кнопку "Отмена" 
   - Нажать крестик в окне прогресс-бара
3. **Операция корректно прерывается** без повреждения данных
4. **Диалог закрывается** с сообщением об отмене операции
