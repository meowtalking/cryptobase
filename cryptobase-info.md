# CryptoBase - Защищенное хранилище файлов с версионностью

## Обзор проекта

**CryptoBase** - это настольное приложение на Python/PyQt5 для безопасного хранения файлов с поддержкой версионности, шифрования и целостности данных. Приложение обеспечивает автоматическое отслеживание изменений файлов, создание бэкапов и защиту данных с использованием современных криптографических алгоритмов.

## 🗄️ Модели данных

### FileRecord - Основная информация о файле
```python
- id: Integer (Primary Key)
- name: String (имя файла)
- path: String (полный путь, уникальный)
- algorithm: String (алгоритм хэширования)
- current_hash: String (текущий хэш файла)
- password_hash: String (bcrypt хэш пароля файла)
- created_at: DateTime
- updated_at: DateTime
- status: String (OK/Modified/Missing)
- versions: Relationship (связь с версиями)
```

### FileVersion - Версии файлов
```python
- id: Integer (Primary Key)
- file_id: Integer (Foreign Key)
- version_hash: String (хэш версии)
- created_at: DateTime
- comment: String (комментарий к версии)
- user_name: String (кто создал версию)
- location: String (local/server)
```

### LogEntry - Системные логи
```python
- id: Integer (Primary Key)
- action: String (add_file, delete_file, login_success и т.д.)
- file_name: String
- result: String (результат операции)
- user_name: String
- timestamp: DateTime
```

### Setting - Настройки приложения
```python
- id: Integer (Primary Key)
- key: String (уникальный ключ настройки)
- value: String (значение настройки)
```

## 🔐 Безопасность

### Криптография
- **AES-256-GCM** для шифрования контейнера бэкапов
- **bcrypt** для хэширования паролей файлов
- **PBKDF2** для deriving ключей из паролей
- **Argon2** для мастер-ключа приложения
- **SHA-256** для хэширования файлов

### Защита данных
- **Зашифрованный контейнер** `~/.cryptobase/backups.enc`
- **Права доступа** 700/600 на директорию и файлы
- **Мастер-ключ** на основе Argon2 с солью
- **Автоматическая блокировка** приложения (настраиваемая)
- **Логирование всех действий** с именем пользователя

### Хранение паролей
- **Мастер-пароль**: Argon2 + соль в `~/.cryptobase/master_salt.bin`
- **Пароли файлов**: bcrypt хэши в базе данных
- **Сессии**: временные ключи в памяти

## 🔄 Жизненный цикл файла

### Добавление файла
1. Пользователь выбирает файл → диалог пароля (опционально)
2. Создается запись в БД (FileRecord)
3. Вычисляется хэш файла
4. Создается первая версия в контейнере
5. Запускается FileWatcher для мониторинга

### Изменение файла
1. FileWatcher обнаруживает изменение
2. Проверяется хэш файла
3. Создается новая версия в контейнере
4. Обновляется запись в БД
5. Логируется операция

### Удаление файла
1. Пользователь выбирает стратегию удаления
2. Диалог сохранения версий (если есть версии)
3. Асинхронное удаление с прогресс-баром
4. Возможность отмены на любом этапе
5. Удаление из БД, контейнера, и/или диска

## 🛡️ Меры безопасности

### Защита от атак
- **SQL Injection**: SQLAlchemy ORM
- **Path Traversal**: валидация путей файлов
- **Timing Attacks**: bcrypt для паролей
- **Brute Force**: мастер-ключ с Argon2

### Резервирование
- **Автоматические бэкапы** версий
- **Шифрованное хранилище** данных
- **Целостность данных** через хэши
- **Логирование** для аудита

### Восстановление
- **Восстановление версий** из контейнера
- **Проверка целостности** данных
- **Экспорт** в plaintext или зашифрованном виде
- **Миграция** между системами
